# 십이지신 — 시간의 조각

> 십이지신의 어긋난 시간을 바로잡고 원래의 세계로 돌아가라.

## ⬇️ 다운로드 & 플레이

> 이 게임은 별도의 실행 파일(`.exe`)을 제공하지 않습니다. **Godot 엔진으로 직접 열어** 실행합니다.

1. **[Godot Engine 4.6](https://godotengine.org/download)** 을 내려받습니다. (설치가 필요 없는 단일 실행 파일)
2. 이 저장소의 **[Releases](https://github.com/SeungJun221/zodiac/releases)** 페이지에서 최신 버전의 소스 `.zip` 을 내려받고 압축을 풉니다.
3. Godot 엔진을 실행 → **가져오기(Import)** 를 누르고, 압축을 푼 폴더 안의 **`project.godot`** 파일을 선택합니다.
4. 프로젝트가 열리면 우측 상단 **▶ 실행** 버튼(또는 `F5`)을 눌러 플레이합니다.

> 처음 가져올 때 에셋을 불러오는 데 잠시 시간이 걸릴 수 있습니다.

### 소스에서 클론하기 (선택)

```bash
git clone https://github.com/SeungJun221/zodiac.git
```

클론한 폴더의 `project.godot` 를 Godot 엔진에서 가져오면 동일하게 실행됩니다.

- 엔진 버전: **Godot 4.6** (Forward+)
- 기본 해상도: 1280 × 720
- Windows 환경에서는 Direct3D 12 드라이버를 사용합니다.

## 🎮 조작법

| 동작 | 키 |
|------|-----|
| 이동 | `W` `A` `S` `D` 또는 방향키 |
| 공격 | `Space` |
| 대쉬 (축시 장착 시) | `F` |
| 늑대 소환 (술시 장착 시) | `Q` |
| 상호작용 / 습득 | `E` |
| 인벤토리 | `Tab` |
| 설정 / 일시정지 | `Esc` |

> 시간의 조각은 습득 후 **인벤토리(`Tab`)에서 직접 장착**해야 스킬이 활성화됩니다. 슬롯을 우클릭하면 장착/해제가 토글됩니다.

## 📖 이야기

계명대학교 행소박물관 견학 날, 전시실 한켠의 **십이지신 병풍**과 눈이 마주친 순간 — 호랑이의 두 눈이 황금빛으로 번쩍이고 세상이 소용돌이친다. 눈을 떠보니 낯선 이세계 한가운데, 손에 쥔 것은 청동기 시대의 녹슨 **청동검** 한 자루뿐.

십이지신이 다스리는 이 뒤틀린 세계에서 살아남아, 어긋난 시간의 조각을 되찾는 여정이 시작된다.

## 🎯 기획 의도 · 주제 선정 배경

우리 전통문화 속 **십이지(十二支)** 신앙을 게임이라는 친숙한 매체로 재해석하는 것에서 출발했습니다. 계명대학교 행소박물관 견학 중 마주한 ‘십이지신 병풍’의 강렬한 인상을 “박물관에서 이세계로 빨려 들어간 주인공”이라는 판타지 서사로 확장했습니다.

- **전통문화의 게임화** — 열두 띠 동물과 십이시(十二時) 개념을 단순 배경이 아니라 핵심 게임 메커니즘으로 끌어들였습니다.
- **‘시간’이라는 테마의 일관성** — 십이지가 곧 하루의 열두 시각(자시·축시…)을 의미한다는 점에 착안하여, 보스를 처치해 얻는 보상을 **‘시간의 조각(時)’** 으로 설정하고 이를 캐릭터의 능력(스킬)으로 연결했습니다.
- **교육적·문화적 가치** — 플레이 과정에서 십이지의 순서와 각 시(時)의 의미를 자연스럽게 익히도록 ‘십이지신 순서 퀴즈’와 인벤토리 도감 설명을 배치했습니다.

## ✨ 특징

- **9개 스테이지** — 일반 전투 스테이지와 보스전, 그리고 퍼즐로 마무리되는 엔딩 스테이지
- **3종 십이지신 보스전** — 보스마다 고유한 페이즈/패턴
  - 🐂 **소(丑)** — 좁은 시야를 파고드는 돌진, 청동 항아리 운석 낙하, 8방향 파동 공격
  - 🐕 **개(戌)** — 인간에서 늑대로 변신, 화면이 어두워지는 암실 구간 + 도약/광폭/지그재그 돌진
  - 🐒 **원숭이(申)** — 전투 전 **십이지신 순서 퀴즈**, 맞히면 싸우지 않고 통과
- **시간의 조각 = 스킬** — 보스를 처치해 얻은 조각을 인벤토리에서 장착해 능력 해금
  - **축시(丑時)** → `F` 무적 대쉬 (적을 관통하며 피해)
  - **술시(戌時)** → `Q` 늑대 동료 소환 (자동 추격·공격)
  - **신시(申時)** → 마지막 시계 퍼즐의 열쇠
- **연출** — 타이핑 대사 시스템, 프롤로그 컷신, 페이즈별 보스 체력바, 셰이더 기반 암실 효과, 엔딩 시퀀스
- **진행 저장** — 클리어한 스테이지와 인벤토리, 음량 설정 자동 저장

## 🖥️ UI/UX 설계

- **즉시 이해되는 조작** — WASD(이동)+`Space`(공격)의 보편적 배치. 첫 진입 시 ‘조작법’ 화면을 노출해 학습 비용을 최소화.
- **최소 정보 HUD** — 좌상단 하트 체력과 우상단 대쉬 게이지만 상시 노출, 안내는 하단 메시지로 잠깐 표시 후 사라짐.
- **점진적 성장감** — 보스 보상을 강제 적용하지 않고 **인벤토리에서 직접 장착**하게 하여 선택권과 획득감을 부여.
- **명확한 전투 피드백** — 피격 시 적색 플래시·넉백, 보스 페이즈 전환 시 체력바 색(초록→노랑→빨강)과 ‘★’ 표시.
- **몰입형 연출** — 보스 조우마다 타이핑 대사 인트로로 긴장감을 주고, 전투 시작 시 체력바가 서서히 페이드인.

## 📂 프로젝트 구조

```
zodiac/
├── project.godot          # 프로젝트 설정 · 입력 맵 · 오토로드(PlayerStats)
├── scenes/                # 씬 파일(.tscn)
│   ├── main.tscn          # 게임 전체 흐름 관리(화면 전환·보스/포탈 처리)
│   ├── levels/            # 스테이지 1~9
│   ├── lobby / prologue / controls / level_select ...
│   └── 보스 · 플레이어 · 적 · UI 씬
├── scripts/               # GDScript(.gd)
│   ├── player.gd, player_stats.gd (오토로드)
│   ├── cow_boss / dog_boss / monkey_boss ...
│   ├── zodiac_quiz.gd, clock_puzzle.gd (퀴즈/퍼즐)
│   └── hud / dialogue_box / portal ...
├── tools/                 # 에디터용 스프라이트 생성 스크립트
└── assets/                # 이미지 · 오디오 · 프롤로그 컷신
```

최상위 **Main** 씬이 화면 전환(로비→프롤로그→레벨→엔딩)을 총괄하며, 플레이어의 체력·인벤토리는 전역 싱글톤 **PlayerStats**(Autoload)에 저장되어 씬이 바뀌어도 유지됩니다.

## 🧪 개발 중 문제 해결 & 테스트

반복 플레이테스트와 경계(엣지) 케이스 검증, 정적 코드 점검을 통해 다음 결함들을 발견하고 해결했습니다.

| 문제 현상 | 원인 | 해결 |
|---|---|---|
| 보스 체력바가 로비로 나간 뒤에도 남음 | 체력바가 스테이지(LevelRoot)가 아닌 **Main의 자식**으로 생성되고 `CanvasLayer`라 HUD 숨김 영향도 안 받음 | 모든 이탈 경로에서 호출하는 `_remove_boss_health_bar()` 공통 헬퍼로 통일 |
| 개(戌) 보스 처치 후 하단 체력바가 안 사라짐 | 개 보스만 `await animation_finished`로 `died`를 보내 시그널을 놓치면 미발생 | 소·원숭이처럼 **타이머 기반**으로 `died`를 확실히 발생 |
| 보스 인트로 대화가 빈 칸으로 멈춤 | 매 프레임 문자열을 이어붙이는 타이핑 방식의 취약점 | `visible_characters` 방식으로 교체(전체 문장을 먼저 넣고 표시 글자 수만 증가) |
| 메뉴/인게임 음량·슬라이더 값 불일치 | 두 화면이 퍼센트↔dB 변환 공식을 다르게 사용 | 변환 함수를 동일한 매핑으로 통일 |
| 체력 음수 시 UI 갱신 오류 가능성 | 음수 체력이 하트/체력바 인덱스를 음수로 만듦 | 표시 직전 `max(체력, 0)`·`clampf()` 방어 처리 |

## 🌱 기대효과 및 활용방안

- **전통문화 교육 콘텐츠** — 플레이를 통해 십이지의 순서와 십이시(時)의 의미를 자연스럽게 학습. 박물관·학교 연계 체험형 자료로 활용 가능.
- **박물관 전시 연계** — 십이지신 병풍 등 실제 유물과 연결된 ‘이세계 모험’ 콘셉트의 인터랙티브 체험물로 확장 가능.
- **확장성** — 보스/스테이지가 공통 구조로 설계되어 나머지 십이지신(쥐·호랑이·용…)을 손쉽게 추가 가능.

## 🏆 프로젝트 성과

- 로비~엔딩까지 이어지는 **9스테이지 완결형 게임** 구현(저장/불러오기 포함)
- 공통 타깃팅·넉백·페이즈 구조 위에 **보스 3종의 고유 AI/패턴**(운석·변신·암실·퀴즈) 구현
- ‘시간의 조각’ 기반 **인벤토리·스킬 장착**(무적 대쉬, 늑대 소환)과 도감형 설명
- Godot 4.6 / GDScript 숙련 — 셰이더·Tween·물리 도형 질의·동적 스프라이트 생성 툴 작성, Git/GitHub 협업
